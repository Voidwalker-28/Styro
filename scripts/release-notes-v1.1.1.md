# Styro v1.1.1

Hotfix for the v1.1.0 launch crash.

## Fixed

- **No more force-close on launch** — the native launcher module is now properly bundled into the APK (v1.1.0 shipped without it due to a build linking issue).
- The JS bridge can never crash the app even if the native side is missing — worst case it shows "Needs Android."

## Everything from v1.1.0

- Real default launcher support (HOME role, "Set as home app" card)
- Real installed apps with real icons in App Space
- Real app launching on tap
- New geometric app icon (white on black)
- Cleaned permissions

Download **Styro-v1.1.1.apk** below. Upgrades from v1.0.0/v1.1.0 keep your settings.
