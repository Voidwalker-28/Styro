# Styro v1.0.0 — first preview APK

**Your phone, arranged around you.** A free, calm, futuristic launcher-style experience for Android. No accounts. No paywalls. No ads. No tracking.

This is the first public preview build of Styro. Install the APK below and try it out.

## What's inside

- **Calm home surface** — a quiet vertical favorites rail, glanceable widgets, no noise
- **App Space** — full app list with live search, categories, and an alphabet index
- **Folders** — group apps into folders with a clean overlay
- **Widget stacks** — stack and flip through widget cards on the home surface
- **Gesture editor** — customize gestures your way
- **Deep Customize screen** — grids, per-surface settings, themes
- **Backup export/import** — your setup travels with you
- **Phone + tablet, portrait + landscape** — layouts adapt to the device

## Honest boundary

Anything needing real Android system APIs (default launcher role, installed-app discovery, notification access, wallpaper reading, real widgets) is clearly labeled *Preview simulation only* or *Requires native Android integration*. Styro never fakes a system action.

## Install

1. Download `styro-v1.0.0.apk` below
2. Open it on your Android phone — allow "install unknown apps" if prompted
3. That's it. No sign-in.

Built with Expo (React Native + TypeScript + expo-router). Source is in this repo.
